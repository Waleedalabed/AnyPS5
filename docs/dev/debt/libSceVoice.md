# libSceVoice technical debt

### Silent stubs

- [sceVoiceGetPortAttr](../../../core/libs/prx/libSceVoice/Export.cpp) (libSceVoice) - attribute 1001 writes one zero byte and returns 0 for an existing port; the backend processes no voice audio. PPSA34501 requests size 1 and reads one byte on success, and this fallback avoids its startup exception. The name follows attribute 1001 (`CELLVOICE_ATTR_VAD`) (Voice Activity Detection) in [RPCS3](https://github.com/RPCS3/rpcs3/blob/master/rpcs3/Emu/Cell/Modules/cellVoice.h), not confirmed for the PS5. The correct result, eligible port types and behaviour are unknown.

### Unknown function info

- [sceVoiceResetPort](../../../core/libs/prx/libSceVoice/Export.cpp) (libSceVoice) - the `(uint32_t portId)` signature is the PS Vita one in [VitaSDK](https://github.com/vitasdk/vita-headers/blob/ae5808f3105c42fa3373ba4ab64ab54e2e3ca848/include/psp2/voice.h#L503-L514) and the PS3 `cellVoiceResetPort` in [RPCS3](https://github.com/RPCS3/rpcs3/blob/be69c054eeac57e2e671697a463473d37fe5a7b2/rpcs3/Emu/Cell/Modules/cellVoice.cpp#L493-L510); that the PS5 library takes the same argument is assumed. A reset drops the packets `sceVoiceWriteToIPort` queued, so the port takes writes again, and keeps the port's connections, volume and mute flag. An uninitialized library or an unknown port throws like the other port calls; the console's error codes are not measured. PPSA23566 imports it
- [sceVoiceWriteToIPort](../../../core/libs/prx/libSceVoice/Export.cpp) (libSceVoice) - the `(uint32_t portId, const void* data, uint32_t* size, int16_t frameGaps)` signature is the PS3 `cellVoiceWriteToIPortEx2` in [RPCS3](https://github.com/RPCS3/rpcs3/blob/master/rpcs3/Emu/Cell/Modules/cellVoice.cpp), the only PS3 form that takes a frame count; the PS5 library exports a single `sceVoiceWriteToIPort` (`YeJl6yDlhW0`, [3.20 catalogue](https://github.com/DNNDHH/PS5-3.20_Libs/blob/main/libSceVoice.c)) with no `Ex` variant, so that it takes the same four arguments is assumed. It checks `data`, `size` and the port like the other port calls, throws for a negative frame count, and rejects a port that is not an input port; `size` is in and out and the packet is queued in the port, a write that does not fit reporting 0 bytes so the caller retries, as RPCS3 does for the argument checks. The queue holds 5 frames of 20 ms, the frame being `(bitrate * 20 + 7999) / 8000` for a voice port, which is what `sceVoiceGetPortInfo` reports, and 3840 bytes for a port that declares no bitrate, which that call reports as 0. The console's queue depth, the meaning of its frame count and the `size` it reports on a refused write are not measured. `sceVoiceGetPortInfo.byte_count` stays 0 and `sceVoiceReadFromOPort` returns no bytes, because the queued packets belong to the console's voice engine, which this library has none of: [libSceVoiceChat](../../../core/libs/prx/libSceVoiceChat/Export.cpp) reports every session request as signed out, so no packet can reach an output port
- [sceVoiceGetResourceInfo](../../../core/libs/prx/libSceVoice/Export.cpp) (libSceVoice) - the `(VoiceResourceInfo* info)` signature and port limits (7 voice inputs, 7 voice outputs, 1 device input, 1 device output, 64 total ports) are the PS Vita ones in [VitaSDK](https://github.com/vitasdk/vita-headers/blob/ae5808f3105c42fa3373ba4ab64ab54e2e3ca848/include/psp2/voice.h#L150-L157); that the PS5 library uses the same layout and limits is assumed. An uninitialized library or a null output pointer throws like the other Voice calls; console limits and error codes are not measured. PPSA23566 imports it
- [sceVoiceEnableChat, sceVoiceDisableChat](../../../core/libs/prx/libSceVoice/Export.cpp) (libSceVoice) take no arguments and return 0, following [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Audio/AudioOut2.cs#L460-L464) and the `sceAudioOut2EnableChat` model. The host mixes no chat audio, so the calls only record whether chat audio is enabled and fail when the library is not initialized. Console error codes and chat session requirements are unverified. PPSA23566 imports them
